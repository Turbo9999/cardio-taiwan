# Cardio Taiwan

Cardio Taiwan is a fitness gamification/community web app prototype.

## v0.1
- Mobile-first UI
- Daily quest
- XP / level / streak
- Class schedule browsing
- Workout completion
- Badge collection
- Community prototype
- Profile
- PWA manifest
- Supabase starter schema

## World Gym data
The current prototype includes a small schedule snapshot based on the publicly accessible World Gym Taiwan aerobic-class schedule for New Taipei Banqiao Fuzhong. It is intentionally not presented as a live API feed.

Official source:
https://www.worldgymtaiwan.com/en/find-a-club/new-taipei-banqiao-fuzhong/aerobics-class-schedule

Before production use, implement a compliant server-side data ingestion/synchronization process and confirm applicable permissions/terms.

## Deploy
This is a static prototype and can be deployed directly to Vercel.
